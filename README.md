# Very Basic RPG (VBG)

VBG is an asynchronous, fiction-first tabletop RPG. This repository preserves the base game and publishes setting modules that intentionally modify its rules.

## Contents

- [Base rules](base%20rules/Very%20Basic%20RPG%20%28VBG%29.md) — VBG v1.4.2
- [Base traits](base%20rules/) — major traits, minor traits, abilities, and creature blueprint
- [VBG-Z](Zombie%20Module/) — survival-horror module v2.0
- [Baseline comparison](docs/revision-notes/BASELINE_COMPARISON.md) — documented mechanical changes and source conflicts
- [Refinement backlog](docs/revision-notes/REFINEMENT_BACKLOG.md) — decisions to make before revising the base game

## Repository convention

- Keep the base rules genre-neutral.
- Put module-specific overrides in the module folder; label every override explicitly.
- Update the baseline comparison whenever a module changes a core rule.
- Do not silently overwrite source material; record an approved revision in Git history.

## Current status

The imported documents are an unedited baseline. No rules have been reconciled yet.
