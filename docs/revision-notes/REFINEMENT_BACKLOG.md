# Base-game refinement backlog

Use this as the decision order for the next VBG revision. Resolve higher items before rewriting downstream sections.

## 1. Pick the universal resolution engine

Choose one:

- Retain d10 pools and adapt VBG-Z's TN/margin concepts only where useful.
- Adopt d20 + modifiers as the new VBG core.
- Define both as alternate engine modules; this creates extra support and balance work.

This decision controls character math, difficulty guidance, outcomes, creature threats, and every module.

## 2. Define a single health model

Decide the meanings and defaults for:

- current and maximum Strain;
- Armor's absorption and repair rules;
- conditions, being Downed, death, and recovery;
- whether healing scarcity is a base rule or a module dial.

## 3. Separate core rules from genre dials

Keep these core if wanted: trait bonuses, action economy, monster-facing rolls, PP, inventory slots.

Treat these as module dials: supernatural Domains, firearms/ammunition, infection, noise clocks, safe rooms, V-ACT, and strict healing.

## 4. Standardize terminology and authority

- One canonical glossary per published version.
- One authoritative equipment catalog per module.
- Player books state play rules; GM books state procedures and hidden guidance.
- Every override names the base rule it replaces.

## 5. Reconcile character options and advancement

- starting trait count and starting gear;
- stat ranges and hard caps;
- Ability Domain versus Tactical Specialization;
- PP prices and caps;
- inventory expansion and stacking rules.

## 6. Define movement resolution

The current documents name movement actions and distance bands, but do not establish a universal movement allowance. Without one, a player can narrate implausible travel within a single action.

Decide and state:

- what a normal movement action reaches in an exploration scene;
- what a Major Action such as Sprint/Reposition reaches in a threat scene;
- whether a Minor Action can move within a room or change a distance band;
- how terrain, pursuit, encumbrance, and conditions constrain movement;
- when long-distance travel requires a Transition Scene rather than an action roll.

Use fictional zones/distance bands rather than exact feet if keeping play-by-post lightweight. The rule should make each declared movement's destination and time cost clear.

Create `VBG v1.5 design decisions.md`: one short ruling for each item in sections 1–2, followed by a rewrite of the base core rulebook. Do not revise module prose until those decisions are locked.
