# Release notes

## VBG 2.2 — core promotion, 2026-09-27

VBG 2.2 is now the current core ruleset, rather than a working draft. This release changes organization and status, not gameplay mechanics.

- Moved the six-document core from `drafts/vbg-2.2/` to `rules/` and replaced draft approval notices with current rule authority.
- Removed Port Vane and its living-world integration document.
- Retained Arcana Deck under `modules/arcana-deck/`, including every card catalog, illustration, diagram, and art provenance file.
- Retained Charge Combat under `modules/charge-combat/` and VBG-Z under `modules/zombie/`.
- Archived VBG 1.4.2, historical audits, campaign planning, and the remaining living-world proposals.
- Removed obsolete relocation notices, standardized document filenames, and updated relative links.

## Release boundaries

The core Decision Log has no pending rules decisions. Promotion establishes the authoritative baseline; it does not demonstrate balance or certify completed playtesting.

Arcana Deck retains its confirmed/proposed distinctions and untested status. Charge Combat remains experimental and untested. VBG-Z remains a separate legacy rules package with known conflicts recorded in the comparison. No restriction-for-power mechanic or new combat design is introduced by this release.

## Editorial status

- **Q21 — Filenames:** settled. Documents use kebab-case; folder indexes use `README.md`. Existing asset names remain intact.
- **Q20 — Licence and author credit:** unresolved. No licence, attribution, or redistribution permission is invented by this release.
