# Port Vane

**Status:** working draft · **Revised:** 2026-09-24
**Owns:** version status, reading order, and the authority rules for this setting set.

> Setting only. Mechanics come from the [VBG 2.2 document set](../vbg-2.2/README.md). Anything marked pending is not playable; see [Open Questions](Open%20Questions.md).

## 1. What this is

Port Vane is a setting module for VBG: a rotting coastal fortress-city in 2013, where metaphysical anomalies called Domains are a licensed industry and the corpses of the things that come through the tears are a commodity.

It is built for a **player-centric campaign** — factions hold power, players hold memberships, and scenes run with or without a DM. See [Campaign Format](Campaign%20Format.md).

Two things to know before reading further. **Every faction is playable and none is the antagonist**; the Carrion are the threat, and they are the only one. And **the city was already running** before any character arrived — faction business advances on a schedule, not on player attention.

## 3. Authority

| Source | Owns |
|---|---|
| [VBG 2.2](../vbg-2.2/README.md) | All mechanics — resolution, Strain, actions, damage, inventory, progression. |
| Campaign Format | How this campaign is structured, who may decide what, and the membership rules. |
| Setting Guide | World facts, geography, terminology. |
| Factions | Faction composition, aims, tensions, and ranks. |
| Domains | The Domain catalog, loudness, Dead Static, Burnout, and setting gear. |
| Traits | The Major and Minor Trait catalog for this setting. |
| Carrion | Creature types and behaviour. Stat values remain VBG's to own. |
| Open Questions | Unresolved items. A pending entry is not a rule. |

**This module scaffolds on VBG 2.2; it does not fork it.** Setting text never overrides a VBG rule, and where this set appears to state a mechanic it is describing fiction, not changing the game. The module adds exactly three mechanical things, each of which plugs into a socket VBG already has:

| Addition | Socket it plugs into |
|---|---|
| **Domain loudness** | A noise trigger feeding VBG's shared Noise Clock. Not a second clock. |
| **Burnout**, a 0–4 track | An added track and one added way to spend Strain (Overreach). Nothing else about Strain changes. |
| **Catalogs and gear entries** | Domains, Traits, and items written in the Item Glossary's own format and bands. |

Everything else — resolution, damage, the cycle, harm, inventory, progression — is read from [VBG 2.2](../vbg-2.2/README.md) unchanged.
