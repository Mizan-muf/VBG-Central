# Very Basic RPG 2.2

**Status:** current core rules · **Version:** 2.2 · **Revised:** 2026-09-27  
**Owns:** version status, reading order, and the authority rules that govern this document set.

> VBG 2.2 is the current core ruleset. Modules apply only when explicitly adopted; see the [rule authority](README.md#3-rule-authority).

## 1. What this is

VBG is an asynchronous, fiction-first tabletop RPG. Players declare what their characters attempt; the GM presents the situation, risks, and threats, then resolves uncertain outcomes.

This folder holds the complete VBG 2.2 document set. Five documents cover the whole game, split by reader and purpose. Read them in the order below.

## 2. Reading order

| # | Document | Read it to |
|---:|---|---|
| 1 | [Player Rulebook](player-rulebook.md) | Create a character and play. Start here. |
| 2 | [GM Guide](gm-guide.md) | Run scenes and adjudicate rules. |
| 3 | [Creature Blueprint](creature-blueprint.md) | Build and run creatures. |
| 4 | [Item Glossary](item-glossary.md) | Look up equipment, acquisition, and value bands. |
| 5 | [Decision Log](decision-log.md) | Check what is settled and what changed. |

A new player needs only the Player Rulebook. A GM needs the Player Rulebook and the GM Guide, then the Creature Blueprint when preparing an encounter.

**Nothing in this set is pending.** As of 2026-09-24 every rule the Decision Log tracked is written into the document that owns it.

## 3. Rule authority

Each rule has exactly one owning document. When two documents appear to disagree, the owner wins.

| Document | Owns |
|---|---|
| Player Rulebook | Shared player-facing mechanics: resolution, characters, scenes, abilities, harm, inventory, progression. |
| GM Guide | GM procedures. It does not override shared mechanics. |
| Creature Blueprint | Creature construction. |
| Item Glossary | Item statistics, acquisition, stack sizes, kit contents, consumable values, materials, and crafting. |
| Decision Log | Unresolved rules and editorial status. A pending item is not a playable rule. |

Link to the owning document rather than copying a shared rule into another file.

## 4. Document conventions

- Every document opens with the same status block: version status, revision date, and what it owns.
- Sections are numbered so any rule can be cited as *document § number*.
- Pending procedures carry a short local notice at the affected rule and a full entry in the Decision Log.
- Examples and quick references summarize rules stated elsewhere. They never introduce a cost, bonus, or exception of their own.

## 5. Relationship to other VBG material

VBG 2.2 is the current core ruleset, promoted from draft on 2026-09-27. This is the authoritative set for new VBG games. The [v1.4.2 archive](../archive/README.md) preserves the earlier edition; [VBG-Z](../modules/zombie/README.md) remains a separate legacy module. Neither overrides these rules.

This promotion establishes the rules baseline; it does not establish playtest results or proven balance. See the [release notes](../docs/release-notes.md).

**Optional modules build on this set.** Each module owns its additions and explicitly lists any overrides of §3 owners. Everything else stays with the core. Use the [module index](../modules/README.md) to choose a package; Arcana Deck and Charge Combat are separate alternatives, not automatically compatible. No setting is required.
