# Individual Domain sets

Each file contains one Domain, its Anchor-based bodily mark, and two suggested starting Mastered techniques. Shared costs, keyword order, and unresolved rules are included in each set for separate reading.

Use the [Domain and technique templates](../templates.md) when creating or expanding a set.
